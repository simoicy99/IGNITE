IGNITE API Documentation

Complete reference for the IGNITE skill-based gaming platform API.

Base URL

http://localhost:3001/api/v1 https://api.ignite.gg/api/v1

Authentication

All endpoints (except login/register) require a Bearer token in the Authorization header.

POST /auth/login

Authenticate and receive a JWT token.

{
  "email": "user@example.com",
  "password": "password123"
}

Wallet

Get Balance

GET /wallet

Get user's wallet balances (available, locked, pending).

{
  "success": true,
  "data": {
    "available": 10000,
    "locked": 0,
    "pending": 0,
    "total": 10000
  }
}

Top Up (Card)

POST /wallet/topup/card

Create a card payment session via Nuvei.

{
  "amountCents": 2000,
  "geo": { "state": "CA", "latitude": 37.7749, "longitude": -122.4194 }
}

Top Up (Bank Transfer)

POST /wallet/topup/bank

Create an ACH bank transfer session via Nuvei.

Matches

List Open Matches

GET /matches?game=CHESS&cursor=&limit=20

Get paginated list of available matches to join.

Accept Match

POST /matches/{id}/accept

Accept a challenge and lock funds in escrow.

Submit Result

POST /matches/{id}/chess-result

Submit match result (I_WON or I_LOST).

{
  "result": "I_WON"
}

Admin

Admin endpoints require an admin JWT token.

Get Platform Stats

GET /admin/stats

Get platform-wide statistics.

{
  "totalUsers": 150,
  "totalMatches": 450,
  "activeMatches": 23,
  "openDisputes": 5,
  "pendingWithdrawals": 12
}

Error Handling

Status Meaning Description
200 OK Request successful
201 Created Resource created successfully
400 Bad Request Invalid request parameters
401 Unauthorized Missing or invalid token
403 Forbidden Insufficient permissions
404 Not Found Resource doesn't exist
429 Rate Limited Too many requests

Rate Limits

  • Authenticated: 100 requests per minute
  • Unauthenticated: 20 requests per minute

Match Status Flow

CREATED → ACCEPTED → FUNDED → IN_PROGRESS → SUBMITTED → VERIFIED → SETTLED
                              ↓                    ↓
                              CANCELED            DISPUTED → RESOLVED
